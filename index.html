RollOne

Real-time biometric attendance for a full lecture hall

Live Visit ↗ Source ↗

Roll call takes about ten minutes. RollOne is sized to check in a 120-student class in under 25 seconds, and to stop proxy attendance while it does.

The problem

120 phones hit the server in the same fifteen seconds, and some students will happily mark a friend present from the canteen.

What I built

  • Four checks in order: rotating HMAC-SHA256 QR over SSE, a line-of-sight PIN, a Haversine geofence, then a FaceNet match.
  • A two-phase check-in with staggered upload slots, so the start of class isn’t a thundering herd.
  • Moved MongoDB to PostgreSQL; UNIQUE + ON CONFLICT make concurrent check-ins idempotent.
  • Redis: atomic Lua rate limiter, TTL state, Pub/Sub to the projector, with fallbacks when Redis is down.

02

OpenForge

A legal RAG assistant that cites the exact section

Live Visit ↗ Source ↗

Answers questions about Indian law across 123 Acts and cites every section it uses. Before changing a line of retrieval, I wrote 120 test questions.

The problem

The first version made up section numbers. The test set showed why: a chunking bug had indexed only 49 of the 358 sections of the BNS.

What I built

  • Hybrid BM25 + dense search, merged with Reciprocal Rank Fusion, then a cross-encoder rerank.
  • An eval harness: Recall@k, MRR and an LLM judge, run on every change.
  • Streaming answers over SSE with clickable citations; first words in under 2.5 s (p95).
  • Recursive-summary memory and production hardening: a JWT forgery fix, OTP limits, SSRF-safe ingestion.
